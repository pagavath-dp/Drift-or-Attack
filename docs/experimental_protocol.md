# Drift-or-Attack experimental protocol — Design C

Status: approved Design C generator, frozen magnitude calibration, baseline/Random Forest, and autoencoder comparison stages. The submitted proposal PDFs are preserved; this document records the operational simulation decisions and their scientific limits.

## Evidence tracks and claims

- **Track A, observational:** use the existing Batch 1 gas/concentration-matched envelope. Report reference departures and exclusions, never natural-drift or cyberattack ground truth. The strict audit covered 3,834 of 7,977 records in Batches 7–10. Gas identity and concentration are laboratory matching metadata.
- **Track B, controlled simulation:** labels are `background` (unmodified extracted-feature input), `synthetic_drift` (an assigned gradual gain change), and `synthetic_attack` (one of five assigned feature-stream manipulations). `background` does not mean verified healthy hardware. Synthetic performance cannot establish real aging or real attack detection.
- Track A departures are never used as Track B labels. No gas, concentration, batch ID, source row ID, generator parameter, or class label is to be offered as a model input.

## Split and evaluation status

| Batches | Use |
|---|---|
| 1 | Track A reference; possible future clean autoencoder reference |
| 2–4 | Track B training and generator scale fitting |
| 5–6 | Future validation and model/decision-threshold selection; no generator tuning |
| 7–10 | Exploratory held-out evaluation; their reference coverage and score distributions were inspected before this protocol was frozen |

All artificial episodes stay within one batch, one gas, and one exact concentration. The order is a stable seeded shuffle of distinct source records, **not acquisition time**. A base episode contains eight unique rows; no source row may enter two base episodes and no exact feature-vector duplicate may appear anywhere in the source archive. Unused rows and groups with fewer than eight distinct rows are reported as exclusions. Every base episode receives one unmodified, one gradual-gain, and one attack variant. They share the same source rows and artificial order, and form one cluster for future uncertainty estimates. The primary balanced design chooses one attack family and one severity per base episode by a seeded order and round-robin assignment within batch. Family-specific stress analysis would be a later stage and is not generated here.

## Prespecified interventions

Master seed: **1729**. A SHA-256 digest of the seed, approved archive digest, batch, source row IDs, and purpose determines shuffles, sensor selection, signs, and noise draws. Do not use process-randomized Python `hash()`. For sensor `s ∈ {0,…,15}`, only zero-based feature indices `8s…8s+7` are altered. One selected sensor is shared by paired variants of a base episode. The source episode and all variants have eight records with no padding. Positions 0–4 are identical in all variants; positions 5–7 are the three intervention positions for drift and every attack. This equal active duration replaces the earlier whole-episode drift ramp to avoid a trivial duration cue. The intended remaining contrast is gradual versus abrupt feature change, which remains an artificial and potentially learnable signature.

| Family | Operation at positions 5, 6, 7 on the selected sensor block | Severity |
|---|---|---|
| `synthetic_drift` | Multiply by `1 + sign × a × r`, where `r = 1/3, 2/3, 1`. Persistent gain ramp. | `a = 0.05, 0.10, 0.20` |
| `bias` attack, matched primary | Add `sign × b × scale_j` to feature `j` at each active position. | `b` is drawn deterministically from the frozen training-only pool for the paired gain-level index. |
| `bias` attack, original stress | The same additive operation, generated and reported separately. | Original approved grid `b = 0.5, 1, 2` remains unchanged. |
| `scaling` attack | Multiply by `1 + sign × a` immediately and hold. | `a = 0.05, 0.10, 0.20` |
| `noise` attack | Add an independent seeded `Normal(0, b × scale_j)` draw for each affected feature and active position. | `b = 0.25, 0.5, 1` |
| `freeze` attack | Copy selected sensor values from source position 4 into active positions. | Fixed three-position duration |
| `replay` attack | Copy selected sensor values from source positions 1, 2, 3 into positions 5, 6, 7 respectively. | Fixed three-position duration |

`scale_j` is IQR/1.349 of source feature `j` over Batches 1–4 only, floored at `1e-12`. This is a simulation scale, not a classifier preprocessing choice. Severity grids, onset, duration, and seed are fixed before model outcomes. No clipping against validation or test ranges is allowed; diagnostics report standardized change magnitudes and non-finite values. These operations edit extracted features, not raw resistance waveforms. Their physical realism is unverified. An attacker can imitate a gradual gain change, so intent cannot be inferred from this simulation.

### Frozen primary bias calibration

For an episode `e` and gain `a`, let `M(e,a)` be the mean of `abs(modified[t,j] − original[t,j]) / scale_j` over the 24 cells at positions 5–7 and the eight features of the episode's selected sensor. The drift operation has progress `1/3, 2/3, 1` at those positions. Feature scales are fitted on Batches 1–4. Apply each gain `0.05, 0.10, 0.20` counterfactually to **all Batch 2–4 base episodes**, producing one sorted pool of `M(e,a)` per gain. The calibration record includes the archive and scale digests, parameters, every training source-episode ID and row ID, every magnitude, the three exact pools, and a canonical JSON SHA-256 digest. Pool entries must be positive and finite.

The primary bias level for an episode is the value at `SHA-256(seed | archive digest | "matched-bias-pool" | episode ID | level) mod pool length` in its gain-level pool. The draw is domain-separated from sensor selection, sign, and noise. Bias is constant across the active positions, so its measured mean standardized change equals the drawn value within floating-point tolerance. Validation and test episodes only consume these frozen pools; they never contribute to calibration, feature scales, or severity selection. No model performance enters this rule. The original `0.5, 1, 2` bias grid is retained as a separate stress condition and the existing Stage 1 reports remain intact.

Matching targets the **training distribution of average magnitude** at each gain level. It does not force equal change within a paired episode or match temporal shape: the drift gain ramps, while bias is abrupt. Source-feature distributions may differ in later batches, and finite family counts can leave a residual mismatch even in training. Diagnostics therefore report paired gaps, per-split/family/severity magnitudes, counts, exclusions, and values beyond the Batches 1–4 feature range for both conditions. The stress and primary variants share source episodes and are correlated; they must never be counted as independent cases in an uncertainty estimate or split across partitions. Laboratory gas/concentration and all generator metadata remain excluded from future model inputs.

The frozen empirical pools contain a finite set of exact bias magnitudes. Reusing those values may itself become a learnable simulation signature if later features reveal the injected change accurately. Current checks establish shared episode order, duration, source rows, and partition, but cannot prove that a future model has no simulation shortcut. This risk must be assessed before classifier training; performance must be described as detection of these specified interventions rather than causal attribution.

## Evaluation definitions

- Track A: coverage, exclusions, and reference-departure rates by batch/gas/concentration, using the Batch 1 q95 envelope plus q90/q99 sensitivity. No natural-drift F1 or attack recall.
- Track B: one prediction per eligible episode variant; macro-F1, per-class precision/recall, confusion matrix, and per-batch/family/severity counts. Attack false-alarm rate = background predicted attack / all background. Any-intervention false-alarm rate = background predicted drift or attack / all background. D2A = synthetic drift predicted attack / all synthetic drift. A2L = synthetic attack predicted background or drift / all synthetic attack. Cluster uncertainty by base episode.
- Binary anomaly-only baseline is evaluated for intervention versus background; single-stage and autoencoder-plus-classifier models, if later approved, use the same compact sequence-aware inputs. Freeze/replay results must be reported separately if sequence eligibility or performance is inadequate. No real-time detection delay is available.
- Future preprocessing and models fit on the allowed reference/training split; model selection uses Batches 5–6; Batches 7–10 remain exploratory because their audit data were inspected. The generator is not tuned on validation/test outcomes.

## Baseline and Random Forest stage

Before fitting, `model_preflight.py` verifies the archive and frozen calibration digests, split/paired-source integrity, equal episode shape and intervention duration, and exact numeric model-input collisions across base episodes. It reports exact reuse of finite-pool bias magnitudes across partitions and paired attack-versus-drift standardized changes by split, family, and severity. These are descriptive diagnostics, not choices made from validation or test outcomes. The finite-pool and fixed temporal signatures remain scientific limitations even when the structural gates pass.

The model feature builder accepts only the eight rows of 128 sensor features and a scale fitted on **unmodified Batches 1–4**. For each of the 128 feature channels, it emits six numeric summaries, for **768 inputs** total: (1) mean of positions 0–4 after subtracting the training median and dividing by the training IQR/1.349; (2) mean of positions 5–7 minus that pre mean; (3) position 5 minus position 4; (4) `(position 7 − position 5)/2`; (5) mean absolute changes from 5→6 and 6→7; and (6) mean absolute differences for the replay lags 5↔1, 6↔2, 7↔3. All difference summaries use the same Batches 1–4 feature scale. Gas, concentration, batch, source IDs, label, family, severity, seed, and selected sensor are evaluation metadata only. A future inference method would need the same artificial eight-record input; these summaries do not establish natural chronology.

- **Anomaly-only baseline:** `IsolationForest` with 200 trees, `max_samples=auto`, `contamination=auto`, seed 1729, fitted on Batch 2–4 `background` feature vectors only. The anomaly score is negative `score_samples`. Select one threshold from all midpoints of unique Batch 5–6 primary scores to maximize **binary** macro-F1 (`background` versus either synthetic intervention); an exact tie takes the higher threshold. Binary detection and false-alarm rates have their own denominators. Drift-versus-attack directional error rates are undefined for this baseline.
- **Single-stage Random Forest:** fit Batch 2–4 primary three-class variants. Fixed grid: 200 trees, `max_features=sqrt`, seed 1729, with `max_depth ∈ {8, unrestricted}` and `min_samples_leaf ∈ {1, 5}`. Select the highest Batch 5–6 primary three-class macro-F1, breaking ties by listed grid order. No validation refit follows selection.
- Apply these same primary-fitted models and primary-selected thresholds/settings to primary and original-stress validation and test conditions separately. The original stress grid is a sensitivity condition, not additional independent training data. Batches 7–10 are evaluated after selection and described as exploratory. No autoencoder or XGBoost is trained in this stage.

The three-class report fixes class order as `background`, `synthetic_drift`, `synthetic_attack`. Macro-F1 averages those three F1 scores; confusion rows are true labels and columns predictions. Attack false alarm = background predicted attack / all background; any-intervention false alarm = background predicted drift or attack / all background; drift→attack = synthetic drift predicted attack / all synthetic drift; attack→background/drift = synthetic attack predicted either other class / all synthetic attack. Every per-batch and family/severity rate includes its denominator. The binary anomaly report uses `background` and `intervention` labels and reports drift and attack detection separately. Synthetic metrics are not estimates of real aging or real attack detection.

## Stage 1 gates

Validate archive provenance, source-row and exact-vector uniqueness, disjoint episodes, variant pairing, split confinement, equal episode length and intervention duration, finite values, class counts in every split, and family/severity counts. Report groups and rows excluded from episode construction. If a gate fails, stop before any model fitting. No synthetic label is written onto a UCI source row.

## Corrective exact-copy diagnostic and autoencoder stage

The permanent preflight checks each eight-feature sensor block in the `active_variation` and `lag_four_similarity` groups for exact zero. Freeze must yield exactly one zero active-variation block and replay exactly one zero lag-four block. Counts are reported by split and family for both simulation conditions. These patterns are detectable construction signatures. Freeze and replay are exact-copy controls and their scores cannot be generalized to ordinary attacks. The 768-feature primary representation and saved baseline results are unchanged.

The autoencoder uses the same 768 numeric summaries, followed by a separate median/IQR/1.349 normalization (spread floor `1e-6`) and `asinh`. For the early-stopping run, this normalization is fitted only on its fitting backgrounds; for the final run, it is refitted on all eligible unmodified Batches 1–4 backgrounds. The 348 final-fit backgrounds are 6, 135, 192, and 15 episodes from Batches 1, 2, 3, and 4 respectively. Batch 1 backgrounds all enter early-stop fitting. Within each of Batches 2–4, the source episodes are SHA-256 ranked using seed 1729; approximately 20% (27, 38, and 3 episodes) are held out for early stopping. Source episode IDs and all related variants remain in their original partitions. The early-stop fit has 280 backgrounds and the holdout 68. No observed reference-departure labels enter autoencoder fitting.

Architecture: `768 → 64 → 16 → 64 → 768`, ReLU hidden layers, linear output, Huber loss with delta 1, Adam learning rate 0.001, L2 kernel penalty 0.0001 on hidden layers, seed 1729, batch size 32, maximum 100 epochs, early-stopping patience 10 and minimum improvement 0.0001. Select the minimum holdout-loss epoch, then restart with seed 1729 and fit that many epochs on all 348 permitted backgrounds. The score is mean elementwise Huber reconstruction error in transformed feature space (without the training regularization penalty). The binary threshold maximizes Batch 5–6 matched-primary background-versus-intervention macro-F1 across candidate score midpoints; higher threshold wins ties. It remains fixed for stress and exploratory test. Refit the selected baseline forest on the original Batch 2–4 primary three-class variants and require exact reproduction of the saved matched-primary validation confusion matrix. Gate: AE score at or below threshold maps to background; above threshold, compare forest drift and attack probabilities, choosing attack only if its probability is strictly higher. No autoencoder or gate parameter is chosen from Batches 7–10.

Report binary AE and three-class gated results separately in matched-primary and original-stress conditions, with per-batch and family/severity denominators. Compare the gated result with the saved forest without claiming improvement absent evidence. All test conclusions remain exploratory and concern assigned synthetic manipulations only.
